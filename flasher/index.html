Ulanzi Pomodoro

Custom Rust firmware that turns the Ulanzi TC001 pixel clock into a self-contained Pomodoro timer with three presets and on-device stats. Plug your TC001 into your computer, then click Install.

Your browser does not support Web Serial. Please use the latest Chrome, Edge or Opera on a desktop computer (Firefox, Safari and iOS are unsupported).
How it works
  • The firmware boots, briefly tries to fetch the current time via NTP (if Wi-Fi was baked in at build time), and then shuts the radio off.
  • The three buttons start preset 1 / 2 / 3 from the idle screen. Pressing again pauses; long-pressing SELECT cancels.
  • Long-press SELECT on the idle screen to open the menu, where you can tweak brightness and the work/rest minutes for each preset.
  • Statistics for the last 32 days are persisted in flash, so a power-cycle won't wipe your streak.

Source code & build instructions: github.com/perseus/ulanzi-pomodoro.
